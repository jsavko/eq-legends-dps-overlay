Set up the DPS overlay

Choose the EverQuest Legends log file to follow.

Log file

    The overlay can only see what your client logs. Type /log on in game if the file below looks stale — or set it once and stop typing it:

    empties the followed eqlog on disk — fight history is kept

    Overlay

    seconds without damage ends the fight
    seconds to wait after the last mob dies

    Triggers

    Everything that can warn you — the rules this app ships with, GINA packages you import, and triggers you write yourself — lives in one window, with a switch for each. Control+Shift+A still mutes the lot for a pull without losing any of those choices.

    Session

    The other half of a play night: what you killed, looted, earned, and advanced. Off by default — nothing below runs, or costs anything, until you switch it on.

    Record:

    Each of these is checked before its patterns run, so anything switched off costs nothing at all rather than being recorded and then hidden.

    Named pets

    Pets called Rhale`s warder are folded into their owner automatically. Summoned pets have their own name and the log never says whose they are, so list them here as Pet = Owner, one per line. Your own pet is detected automatically once it reports to you, and other players' pets are usually worked out from the summon line. You can also map one without leaving the game by typing pet Kibektik = Khanvikt into any chat channel.
