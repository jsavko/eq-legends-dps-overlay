Set up the DPS overlay

Choose the EverQuest Legends log file to follow.

Log file

    The overlay can only see what your client logs. Type /log on in game if the file below looks stale.

    empties the followed eqlog on disk — fight history is kept

    Overlay

    seconds without damage ends the fight
    seconds to wait after the last mob dies

    Alerts

    A floating window, top-center of the screen — unlock the overlay to move it. Each of these is independent; the window opens for whichever are on. Boss timers are no longer among them: they have a window of their own, below.

    Show Custom

    Rates are measured over a 150-hour session in current content, not predicted — your own will differ with the zone. Mobs buffing themselves never warn at any setting: they were measured doing nothing to anybody.

    With all three off the window is closed entirely, so the in-game pet Name = Owner command has nowhere to answer you — it still works, it just cannot say so. Control+Shift+A mutes the lot for a pull without losing these choices.

    Boss timers

    A second floating window, separate from the alerts and placed separately — drag it wherever you keep the buff window. Unlock the overlay to move it.

    A boss ability keeps its row for the whole fight: when the spell fires the row says CAST and re-arms in place, and when a rhythm stops holding up it shows a dash rather than an invented number. Nothing reorders, so a row stays where you learned to look for it. Control+Shift+A silences this panel too.

    Named pets

    Pets called Rhale`s warder are folded into their owner automatically. Summoned pets have their own name and the log never says whose they are, so list them here as Pet = Owner, one per line. Your own pet is detected automatically once it reports to you, and other players' pets are usually worked out from the summon line. You can also map one without leaving the game by typing pet Kibektik = Khanvikt into any chat channel.
